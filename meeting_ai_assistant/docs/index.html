Project Summary

项目简介

本项目是一个移动端优先的 AI 会议纪要整理系统，支持登录、会议创建、文本/录音内容提交、AI 纪要生成、会议收藏、删除、编辑、文件夹管理和重新生成等功能。系统通过 DashScope / Qwen 将会议记录整理为 JSON 结构，并在页面中展示为摘要、关键议题、决策结论、待办事项、风险点和后续跟进。

项目开发重点不在于包装成成熟商业产品，而在于用 AI Coding 完成从想法到可运行原型的闭环：拆解需求、生成代码、调试接口、迭代 Prompt、根据测试反馈修复交互问题，并逐步完善数据管理和移动端 UI。

Features

主要功能

  • 会议记录创建、查看、编辑、删除和批量删除
  • 会议收藏与“全部 / 收藏”筛选
  • 文件夹创建、重命名、删除与会议归档
  • 会议原始记录修改后重新生成纪要
  • 接入 Qwen 模型输出结构化会议结果
  • 针对活动执行策划场景优化 Prompt

AI Coding

我在项目中使用 AI Coding 完成了什么

需求拆解

从“手机用的会议整理系统”这个想法出发，逐步拆成登录、会议列表、新建、详情、编辑、收藏、文件夹、重新生成、异常提示等模块。

功能实现

借助 AI Coding 辅助完成 FastAPI 路由、Jinja 页面、SQLite 数据操作、Qwen 接口调用和前端交互逻辑。

Prompt 迭代

根据生成内容质量问题，多轮调整 Prompt，使输出更偏活动执行策划，关注负责人、截止时间、物料、供应商、场地、风险等信息。

测试反馈修复

根据页面测试中发现的问题，持续修复空内容提交、加载状态、收藏逻辑、文件夹操作、删除确认、编辑状态等细节。
